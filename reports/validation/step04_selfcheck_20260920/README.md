## 修复内容

| 发现的问题 | 现在的处理 |
|---|---|
| 只读 manifest，未交叉检查错误清单 | 必须存在 `errors.csv`，且失败文件、数量与 manifest 一致；矛盾或缺失时隔离包。 |
| 相同存档去重可能掩盖定义指纹冲突 | 在去重前检查全部合格候选包的指纹，冲突立即停止。 |
| 文件名明确组别与目录不一致时仍可能纳入 | 明确的组别标记必须与目录一致，矛盾则隔离整包。 |
| 同一存档可能冒充不同日期或不同实验组 | 相同存档哈希的日期、版本、大小和国家信息必须一致；非起点同一存档不得跨组。共同起点跨组时给出非独立观察点警告。 |
| 定义键表缺行或引用不存在的文件时未停止 | 核对每个文件的定义键数量、引用关系，以及环境声明的文件/键总数；矛盾立即停止。 |
